# Cosmetics: drawing cost

Measured by drawing each dot and trail alone, 300 frames, in a headless browser (CPU drawing, 2x pixels). Only the comparison with the game's default is meaningful, not the milliseconds: a phone's graphics chip will be much faster. 'Draws' = strokes and fills per frame.

| silk | 2.98 | 413 | 2.65x |
| silk (lite) | 1.07 | 77 | 0.96x |
| prism | 4.47 | 732 | 3.98x |
| prism (lite) | 1.80 | 229 | 1.60x |
| jelly | 1.30 | 122 | 1.16x |
| jelly (lite) | 0.70 | 31 | 0.63x |
| eclipse | 2.30 | 196 | 2.05x |
